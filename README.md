# 아침 코어 운동 (EarllnFit)

연세힐 추천 코어 운동 유인물(맥켄지 신전 운동 · 플랭크 · 버드 독)을 매일 아침 따라 할 수 있게 도와주는 웹앱(PWA)과 안드로이드 앱입니다.

## 기능
- **순서 가이드 + 타이머**: 세 운동을 차례로 안내하고, 준비 → 유지 → 휴식 시간을 원형 타이머로 보여줍니다.
- **음성/소리 안내**: "1회. 천천히 상체를 올리세요", "셋, 둘, 하나" 같은 한국어 음성과 삐 소리로 화면을 보지 않아도 따라 할 수 있습니다. 운동 중에는 화면이 꺼지지 않습니다.
- **매일 기록/달력**: 완료한 날을 달력에 표시하고 연속 일수를 보여줍니다. 날짜를 눌러 직접 표시하거나 지울 수 있습니다.
- **자세 설명/주의사항**: 유인물 설명, 손글씨 메모, 자세 포인트를 보여줍니다. 유인물 QR코드의 동영상 주소를 설정에 넣으면 바로 열 수 있습니다.
- **배경음악**: 잔잔한 화음 / 오르골 / 파도 소리 중 골라 운동 중에 깔아줍니다. 음원 파일 없이 앱이 직접 만드는 음악이라 저작권 걱정이 없고 오프라인에서도 나옵니다. 음성 안내 때는 자동으로 작아집니다.
- **기능 켜기/끄기**: 위 4가지 기능을 설정에서 각각 켜고 끌 수 있습니다. 끈 기능은 화면에서 숨겨집니다. 타이머를 끄면 한 번 할 때마다 직접 눌러 넘기는 방식이 됩니다.
- **한국어 / English**: 설정에서 언어를 고르면 화면 글자와 음성 안내가 함께 바뀝니다.
- **아침 알림 (안드로이드 앱)**: 정한 시간에 매일 휴대폰 알림을 보내 줍니다.
- **설정**: 운동별 유지 시간·반복 횟수·세트 수·휴식 시간, 켜기/끄기, 백업 저장/불러오기.

## 기본값
| 운동 | 유지 | 횟수 | 휴식 |
|---|---|---|---|
| 맥켄지 신전 운동 | 7초 (5~10초) | 10회 = 1세트 | 3초 |
| 플랭크 | 20초 | 4회 | 30초 |
| 버드 독 | 5초 | 10회 (좌우 번갈아) | 3초 |

## 안드로이드 앱(APK) 설치하기
1. 휴대폰에서 [최신 Release](https://github.com/earlln/EarllnFit/releases/latest)를 열고 `MorningCore-….apk`를 내려받습니다.
2. 처음 한 번은 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.
3. 새 버전이 나오면 같은 방법으로 받아 덮어 설치하면 기록이 그대로 유지됩니다.

APK는 `main`에 반영될 때마다 `.github/workflows/android.yml`이 자동으로 만듭니다.

### 서명 키에 대해
- 기본으로는 저장소의 개인 설치용 키(`android/keystore/sideload.jks`)로 서명합니다. 저장소가 공개라서 이 키는 누구나 볼 수 있으니, **이 저장소의 Release가 아닌 곳에서 받은 APK는 설치하지 마세요.**
- 더 안전하게 하려면 새 키를 만들어 저장소 Secrets에 `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`를 넣으세요. 그러면 그 키로 서명합니다. (키를 바꾸면 기존 앱을 지우고 다시 설치해야 하므로, 백업을 먼저 해 두세요.)

## 폴더 구성
- `www/` — 웹앱 (GitHub Pages로 배포)
- `android/` — 안드로이드 프로젝트 (Capacitor)
- `scripts/build-android-web.mjs` — 웹앱을 안드로이드 앱용으로 복사
- 로컬 빌드: `npm ci && npm run sync && cd android && ./gradlew assembleRelease`

## 웹앱으로 휴대폰에 설치하기
1. GitHub 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다.
2. `main` 브랜치에 올라가면 `.github/workflows/pages.yml`이 자동 배포합니다.
3. 휴대폰 크롬/삼성 인터넷에서 배포 주소를 열고 메뉴 → **홈 화면에 추가**를 누릅니다.

기록은 휴대폰 브라우저에만 저장되니 가끔 설정 화면에서 **백업 저장**을 해 두세요.

> 통증이 다리로 퍼지거나 저림이 심해지면 운동을 멈추고 담당 의료진과 상의하세요.
